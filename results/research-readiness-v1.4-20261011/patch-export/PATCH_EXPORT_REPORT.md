The new exporter stages changes relative to the official base in an independent temporary Git index. It includes modified/deleted tracked files and new source/binary files even when ignored. The exclusion policy covers `__pycache__`, `.pyc`, `.pyo`, `.pytest_cache`, `.mypy_cache`, `.ruff_cache`, and `.hypothesis`. Each excluded path is recorded with its classification, base/index tracking status, presence, and tracked-change status. New caches are classified again on every export, preventing re-entry through later untracked files. A changed/deleted base-tracked cache path or a newly staged cache path rejects the entire export for explicit review. This avoids silently discarding a potentially intentional tracked fixture edit. Unchanged base cache paths remain in the base tree and produce no diff.

Git metadata aliases, nested metadata, unsupported submodules, unsafe paths, escaping or metadata-reaching symlinks, and symlink parents of tracked files reject. Safe internal symlinks stage the link bytes without reading their targets. The original repository index is unchanged. Every accepted nonempty patch independently passes `git apply --cached --check --binary -` against a second index initialized directly from the official base; empty patches receive an explicit no-changes result.
